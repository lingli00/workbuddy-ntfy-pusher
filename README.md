# WorkBuddy → ntfy 进度推送器

一个**免安装、单文件、便携**的小工具：实时把 WorkBuddy 助手的「任务进度文字」推送到你的手机（通过 [ntfy](https://ntfy.sh)）。

这个工具会**自动监听** WorkBuddy 在本机写下的会话记录，把这类进度文字抓出来，推送到你订阅的 ntfy 主题。于是你不必一直盯着电脑屏幕，手机上就能实时收到「AI 在干啥」。

> 🔒 **隐私说明**：本项目**不内置任何真实 ntfy 地址**。首次运行时请自行填入你自己的 ntfy 服务器地址（格式 `http://服务器:端口/主题`），配置只保存在本机 `config.json`，不会被上传。

## ✨ 功能特性

- **实时推送**：每秒轮询 WorkBuddy 会话日志，增量读取新内容，几乎零延迟。
- **多个推送地址**：可添加任意多个 ntfy 地址（比如自己看一个、给别人看一个），推送时同时发到所有地址，互不影响。
- **只推进度、不推噪声**：自动过滤系统提示（`<system-reminder>` 等），只提取助手说给用户的进度文字。
- **跳过历史**：程序启动时只监控「之后的」新消息，不会把过去的历史刷屏到手机。
- **工具调用可选**：可额外推送「修改了哪个文件 / 执行了什么命令」之类的信息。
- **目录用系统选择器**：监控目录通过系统文件夹选择对话框挑选，选完自动保存。
- **按天存日志**：每次推送都会按天写入 `logs/YYYY-MM-DD.txt`，记录时间、结果（OK/FAIL）、目标地址和内容。
- **开机自动启动**：设置里勾选「开机自动启动」即可，程序会把自身写入注册表 `Run` 项（当前用户登录后后台运行），无需手动放快捷方式。
- **关闭窗口后台运行**：点窗口右上角 ✕ 默认不退出，而是缩到**系统托盘**继续推送；右键托盘图标可「显示窗口」或「退出」。想直接退出可在设置里关闭该选项。
- **单实例互斥**：重复启动会自动把已运行的窗口提到前台，避免同时跑多个实例重复推送。
- **免安装单文件**：打包成一个 `.exe`，双击即用，可拷到任意 Windows 机器运行。
- **设置持久化**：所有配置存为同目录的 `config.json`，下次打开自动生效。

## 🚀 用法（最简单）

1. 准备好你的 ntfy 服务器地址，格式 `http://服务器:端口/主题`（自建服务器或 ntfy.sh 均可）。
2. 双击 `WorkBuddy-ntfy-pusher_v0.2.exe`（或解压便携包后运行）。
3. 首次运行：在「ntfy 推送地址」输入框里填入你的地址 → 点「添加」→ 点「启动」。
   - 需要多个接收方就继续「添加」，删除选中列表里某行后点「删除所选」。
4. 点「浏览…」选择 WorkBuddy 会话记录所在文件夹（默认已自动定位到 `~\.workbuddy\projects`）。
5. 之后 WorkBuddy 里每产生一段进度，你订阅的每个地址都会收到通知。
6. 每天的推送明细在同目录 `logs\YYYY-MM-DD.txt`。

### 开机自启 & 后台运行

- **开机自动启动**：设置里勾选「开机自动启动（登录后后台运行）」即可，程序会写入注册表 `Run` 项，当前用户登录后自动后台运行（无需手动放快捷方式）。
- **关闭到托盘**：直接点窗口 ✕ 不会退出，而是缩到系统托盘继续推送；右键托盘绿色铃铛图标 →「显示窗口」恢复，或「退出」结束程序。
- 若希望点 ✕ 直接退出，取消勾选「关闭窗口时隐藏到托盘后台运行」即可。

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| ntfy 推送地址 | 列表，可添加/删除多个，推送时同时发送 | 空（用户自行填写） |

## 🔧 从源码构建（可选）

需要本机装有 Python 3.8+ 且带 `tkinter`（Windows 官方安装包默认带），以及 `pyinstaller`、`pillow`：

```bash
pip install pyinstaller pillow
pyinstaller --onefile --noconsole --icon=app.ico --add-data "app.gif;." --name "WorkBuddy进度推送器" wb2ntfy.py
```

产物在 `dist/WorkBuddy进度推送器.exe`。

## 🛠️ 工作原理（简述）

WorkBuddy 会把每个会话的完整消息流实时写入
`~\.workbuddy\projects\<项目名>\*.jsonl`。
本工具逐文件记录读取偏移量，新增的行解析后：

- `role == "assistant"` 且类型为进度文字 → 作为通知正文；
- 同时发送到你配置的**所有** ntfy 地址，采用 ntfy 的 **JSON 发布接口**（`POST http://服务器`），
  从而完整支持中文（HTTP header 仅支持 latin-1）；
- 每次推送结果按天追加写入 `logs/YYYY-MM-DD.txt`。
